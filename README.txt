APP PENDÊNCIAS DA QUALIDADE

Como testar no computador:
1. Extraia a pasta.
2. Abra index.html no navegador.
3. Para instalar como PWA e usar câmera/offline corretamente, publique a pasta em HTTPS (ex.: GitHub Pages).

Funções incluídas:
- Cadastro de vistoria por obra, data, responsável, bloco/local e prazo.
- Registro de foto pelo celular.
- Serviço, pendência, ação corretiva, prioridade e status.
- Histórico local no aparelho.
- Alteração de status.
- Resumo final da vistoria.
- Compartilhamento via WhatsApp.
- Compartilhamento nativo do celular.
- Gerar PDF usando a opção Imprimir > Salvar como PDF.
- PWA instalável.
- Funciona offline após a primeira abertura publicada.
- Backup JSON dos dados.

Observação:
Os dados ficam salvos localmente no navegador do aparelho. Nesta versão não existe login, servidor ou sincronização entre celulares.
